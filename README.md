# CineVerse Ultimate - PWA

Installable version of CineVerse (Bollywood / OTT movie tracker) served from GitHub Pages.

## Install on phone
1. Open the live link in Chrome (Android) or Safari (iPhone).
2. Menu -> Add to Home screen / Install app.
3. It opens full-screen like a native app and the shell works offline.

## Files
- index.html - the whole app (single file)
- manifest.json - app name, icons, theme, standalone display
- sw.js - service worker: offline app shell + poster caching
- icons/ - 192/512/maskable/apple-touch icons
